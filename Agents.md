# AGENTS.md — Sitio web para emprendimiento de estética, maquillaje y uñas

## Objetivo
Crear y mantener una página web moderna, elegante, rápida y responsive para un emprendimiento enfocado en maquillaje, uñas, pestañas, cejas, cuidado de la piel y servicios de estética femenina.

## Identidad de marca
- Estilo visual: femenino, elegante, luminoso, profesional y aspiracional.
- Paleta de colores sugerida: rosa suave, nude, blanco, dorado y tono vino.
- Tipografía: una fuente elegante para títulos y una fuente clara y legible para textos.
- Tono de comunicación: cercano, profesional, empoderador y orientado a la belleza personal.

## Estructura del proyecto
- `index.html`: página principal y punto de entrada del sitio.
- `style.css`: estilos globales, diseño responsive, animaciones y tema visual.
- `script.js`: menú móvil, formulario de contacto, interacciones y mejoras de experiencia.
- `assets/`: imágenes del local, trabajos realizados, logo e íconos.
- `AGENTS.md`: instrucciones para agentes de código.

## Secciones del sitio
1. **Inicio / Hero:** nombre del emprendimiento, frase principal y botón para reservar turno.
2. **Servicios:** maquillaje social, maquillaje para eventos, novias, quinceañeras, uñas esculpidas, kapping, esmaltado semipermanente, nail art, pestañas, cejas, limpieza facial y cuidados de la piel.
3. **Galería:** fotos de trabajos realizados.
4. **Testimonios:** opiniones de clientas.
5. **Promociones o precios:** sección opcional y fácil de editar.
6. **Contacto:** dirección, horarios, WhatsApp, redes sociales y formulario de consulta.
7. **Reservas:** botón que lleve a WhatsApp, Instagram o un sistema de turnos.

## Reglas técnicas
- Usar HTML5, CSS3 y JavaScript estándar.
- Diseño mobile-first y totalmente responsive.
- Mantener una navegación simple e intuitiva.
- Usar etiquetas semánticas: `header`, `main`, `section`, `article`, `footer`, etc.
- Incluir textos alternativos en todas las imágenes.
- Mantener buen contraste y accesibilidad.
- Optimizar imágenes para que el sitio cargue rápido.
- No usar frameworks, librerías externas ni dependencias npm sin autorización del usuario.
- Mantener el código limpio, modular y fácil de actualizar.
- Los textos, servicios, precios y datos de contacto deben ser fáciles de editar.

## Flujo de trabajo del agente
1. Leer este archivo antes de modificar el proyecto.
2. Identificar claramente la tarea solicitada por el usuario.
3. Modificar únicamente los archivos necesarios.
4. Mantener compatibilidad con HTML, CSS y JavaScript puro.
5. Preservar el diseño responsive y la identidad visual del sitio.
6. Explicar brevemente los cambios realizados y cómo probarlos.
7. Si una instrucción es ambigua, preguntar antes de hacer cambios importantes.

## Cómo ejecutar el proyecto
1. Abrir la carpeta `estetica-web` en Visual Studio Code.
2. Instalar la extensión **Live Server**.
3. Hacer clic derecho sobre `index.html`.
4. Seleccionar **Open with Live Server**.
5. Abrir la URL generada, normalmente `http://127.0.0.1:5500`.
